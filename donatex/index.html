One Line. Zero Dependencies.

Copy this into your HTML. Replace the wallet address. Your project accepts donations.

HTML 
<!-- DonateX — Accept USDC donations on Base -->
<script
  src="widget.js"
  data-wallet="0xYOUR_WALLET_ADDRESS"
  data-currency="USDC"
  data-amounts="1,5,10,25"
></script>
CONFIGURATION 
/* All options — only data-wallet is required */
<script
  src="widget.js"
  data-wallet="0xYOUR_ADDRESS"      // Required
  data-currency="USDC"              // Token to accept
  data-amounts="1,5,10,25"          // Preset buttons
  data-position="bottom-right"       // Button position
  data-label="Donate"               // Button text
></script>
GIT 
# Clone and copy
git clone https://github.com/wilnowilx/aetheriusxapi.git
cp aetheriusxapi/donatex/widget.js ./your-project/

# Or download just the widget
curl -O https://raw.githubusercontent.com/wilnowilx/aetheriusxapi/main/donatex/widget.js
