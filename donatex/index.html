How It Works

1

Add the Script

Paste one line of HTML. That's it. No npm install, no build step, no config files.

2

Set Your Wallet

Replace the address with your Base wallet. USDC arrives directly — no middleman.

3

Receive Donations

Supporters scan a QR code or connect MetaMask. USDC on Base, instantly.

One Line. That's It.

Copy this into your HTML. Replace the wallet address. Done.

<!-- DonateX — Accept USDC donations on Base -->
<script
  src="https://donatex.aetheriusxapi.com/widget.js"
  data-wallet="0xYOUR_WALLET_ADDRESS"
  data-currency="USDC"
  data-amounts="1,5,10,25"
></script>

Want to self-host? Download the files:

# Clone and copy just the widget files
git clone https://github.com/wilnowilx/aetheriusxapi.git
cp -r aetheriusxapi/donatex/widget.js ./your-project/
cp -r aetheriusxapi/donatex/widget.css ./your-project/

<!-- Then in your HTML -->
<script
  src="widget.js"
  data-wallet="0xYOUR_WALLET_ADDRESS"
></script>
