For Developers

Integrate in Minutes

Simple, powerful, and designed for machines.

Python
# Install: pip install aetheriusx from aetheriusx import Client # Initialize with wallet client = Client("0x677B...7f61") # Call any API - payment is automatic response = client.get( "/v1/crypto/price", params={"token": "ETH"} ) # Response with data print(response.data) # {"price": 2384.50, "change_24h": 2.3}

One line of code.

The Aetheriusx SDK handles everything: wallet connection, payment negotiation, request signing, and response parsing. Just import and call.

  • Auto-negotiates payment via x402
  • Supports Python, JavaScript, Go, Rust
  • Type-safe with full IDE support
  • Built-in retry and error handling
  • Zero configuration needed
