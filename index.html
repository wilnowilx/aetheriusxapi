FAQ

Questions & Answers

aetheriusxAPI is a crypto-native API marketplace where AI agents pay per request in USDC on Base. Built on x402 protocol, it enables machine-to-machine commerce without accounts, subscriptions, or credit cards.

Payments use the x402 protocol. When an AI agent makes a request, the server responds with HTTP 402 (Payment Required). The agent pays in USDC on Base, and the server verifies the payment before returning data.

Base offers sub-cent transaction fees, instant finality, and deep Coinbase integration. It's the ideal L2 for micropayments where every API call costs $0.005-$0.03.

AI agents that autonomously fetch data, research tools that aggregate information, trading bots that analyze tokens, and any application that needs programmatic access to data with instant payment.
